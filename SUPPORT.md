# Support

## ⚠️ I am not a support agent

This repository is a **directory** (a curated list) of mods, servers, and tools for *Sonic.EXE: The Disaster 2D Remake*. 
I am the **curator**, not a developer, server admin, or tech support.

**Please do not send me direct messages (DMs) asking for help.**

## Where to get help

- **Game or mod installation issues:** Contact the original mod author (link is in the mod's entry).
- **Server issues:** Contact the server host (link is in the server's entry).
- **General questions:** Use our [Discussions](https://github.com/FakerNull0/TD2DR-Hub/discussions).
- **Report a broken link or missing mod:** Use our [Issue Forms](https://github.com/FakerNull0/TD2DR-Hub/issues/new/choose).

Thank you for understanding!
