# TD2DR-Hub
---
> A repository directory with everything related to **Sonic.EXE: The Disaster 2D Remake** - Modifications, servers, open-source projects and tools.
---

[![Discussions](https://img.shields.io/badge/Discussions-Join-blue)](https://github.com/FakerNull0/TD2DR-Hub/discussions)

## 📖 About
This repository serves as a central hub for the **TD2DR** community. Whether you're looking for a specific reskin, a public server to play on, or want to share your own creation, you'll find it here.

**Want to add something?** Use our automated Issue Forms to submit a mod or a server, and it will be added to the directory.

* **Need help?** Please read our [SUPPORT.md](SUPPORT.md) first.
