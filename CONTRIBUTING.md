# Contributing to TD2DR-Hub

First off, thank you for considering contributing to the TD2DR-Hub! It's people like you that make this community a great place to share mods and find servers.

## 📌 Ways to Contribute

### 1. Submit a Mod or Server
The easiest way to contribute is by using our automated Issue Forms:
- **[Submit a mod](https://github.com/FakerNull0/TD2DR-Hub/issues/new?template=add-mod.yml)**
- **[Submit a server](https://github.com/FakerNull0/TD2DR-Hub/issues/new?template=add-server.yml)**

Once submitted, a maintainer will review your request. If approved, it will be added to the directory.

### 2. Fix a Typo or Broken Link
If you notice a mistake in the `README.md` or any other file, you can open a **[Pull Request](https://github.com/FakerNull0/TD2DR-Hub/pulls)** directly. For small fixes, a PR is faster than an issue.

### 3. Suggest an Idea or Ask a Question
For anything else, please use our **[Discussions](https://github.com/FakerNull0/TD2DR-Hub/discussions)**. It's a great place to share ideas, ask for help, or talk with other community members.

## 📋 Guidelines

To keep the directory useful and safe, please follow these rules:

- **No pirated content.** Do not link to illegal downloads of the game.
- **No third-party reuploads.** Link to the original mod page (Game Jolt, GameBanana, GitHub, etc.). If the original is gone, please mention that.
- **Public servers only.** Do not submit private, whitelisted, or temporary servers.
- **Be respectful.** Treat everyone with kindness. Toxic behavior will not be tolerated.
- **Check before submitting.** Make sure the mod or server isn't already listed.

## 🛠️ Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the `README.md` with details of changes to the interface, this includes new environment variables, exposed ports, useful file locations and container parameters.
3. Increase the version numbers in any examples files and the `README.md` to the new version that this Pull Request would represent.
4. You may merge the Pull Request in once you have the sign-off of two other developers, or if you do not have permission to do that, you may request the second reviewer to merge it for you.

*(Note: For this specific directory, the PR process mainly involves updating the tables in `README.md` or adding new files to the `data/` folder if we implement that later.)*

Thank you for contributing! 🎉
